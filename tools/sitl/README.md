# SITL Helpers

This directory is reserved for future PX4 and ArduPilot SITL helper scripts.

Current SITL documentation lives in:

- `docs/sitl_testing.md`
- `README.md`

The current MVP supports:

- PX4 SITL telemetry over UDP.
- ArduPilot SITL telemetry over UDP.
- PX4/ArduPilot SITL mission upload/download.

The current MVP does not enable arming, takeoff, landing, RTL, mission start,
force-arm, RC override, or real `MANUAL_CONTROL` transmission.
